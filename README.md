# Personal Portfolio & Technical Blog

A static personal portfolio website and technical blog built using Python and Flask, compiled with Frozen-Flask, and hosted on GitHub Pages.

## 🚀 Features & Stack
* **Backend Framework:** Python / Flask
* **Static Site Generator:** Frozen-Flask
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Form Handling:** FormSubmit Integration
* **Deployment:** GitHub Pages
